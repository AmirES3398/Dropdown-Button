# 🔽 CSS Dropdown Button

A modern and lightweight **Dropdown Button** component built using **HTML5** and **CSS3** only. This project demonstrates how to create a clean dropdown menu with smooth hover animations without using JavaScript.

---

## 🌟 Features

* 🎨 Modern and minimal UI
* ⚡ Built with pure HTML & CSS
* 📱 Simple and responsive layout
* 🔄 Smooth hover transitions
* ⬇️ Animated dropdown icon rotation
* 📋 Dropdown menu with multiple navigation items
* 🚫 No JavaScript required
